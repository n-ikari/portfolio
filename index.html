TempScope｜日本の気温可視化Webアプリケーション

公開サイト ・ GitHub

全国47都道府県の代表地点を対象に、気温推移や天気情報を可視化するWebアプリケーションです。 地域や期間を切り替え、気温の変化をグラフで確認できます。

  • 使用技術：React / TypeScript / Recharts / Open-Meteo API
  • 開発環境：WSL2（Ubuntu）/ Node.js / npm / Vite / Git / GitHub
  • 公開環境：Vercel
